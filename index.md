## Favorite CPSC 120L Labs:

## Lab 1
This lab was the most memorable for me because it was my very first time working with both GitHub
and C++. As someone who was still very new to coding and had only attended a few lectures,
I felt intimidated and unsure of myself at first. I didn’t fully understand how the terminal
worked, and GitHub seemed overwhelming. However, as my partner and I carefully followed the
instructions together, things started to make more sense. Using the pair programming technique,
my partner acted as the navigator and helped me understand each step, especially how to use Git
and BASH commands effectively. By the time we successfully compiled and ran our “Hello, World!” 
program, I felt a real sense of accomplishment.

## Lab 4, part 2 
Lab 4 was fun because my partner and I got to build a working Hi-Lo Guessing Game from scratch.
It was cool to write if statements and see the game respond to our input. We took turns fixing
compile and logic errors, and testing with make test made sure everything worked. I learned how
to write cleaner code, debug better, and work more smoothly with my partner. I feel that my
knowledge of C++ definitely has evolved after this lab.


## Lab 6, part 2
Lab 6 was really fun because my partner and I got to code something based on a real game,
Blackjack, one of my favorite card games. It was cool learning how to assign point values to cards
and write logic to calculate scores. We worked together to fix errors, reran tests a million times,
and made sure the program passed everything. I got better at using functions and understanding how
unit tests work!
